图例预览

先把悬浮窗拖到地图空白处，再用 Win+Shift+S 做区域截图。
不要用“窗口截图”，否则图例不会被包含。配置只保存在本机浏览器。

角度 0° 为正北；顶部的 浮动罗盘按钮随时可以开/关。罗盘和图例可以同时显示，互不影响。配置只保存在本机浏览器。

使用说明

  1. 点击 取色并添加：本地版会先让编辑器让开，然后打开全屏取色层，左键取色、右键或 Esc 取消，取完自动恢复编辑器。没有本地版时用浏览器的取色器；Firefox / Safari / 部分 360 没有取色器，页面顶部会出现兼容提示，截图后按 Ctrl+V（macOS ⌘+V）粘贴，再点图片取色。
  2. 在新增的一行里输入分类名称；继续取色，直到图例完整。
  3. 点击顶部的 浮动图例：会弹出一个没有标题栏、没有按钮的图例小窗，永远盖在其他窗口最上层。把它拖到地图空白处，然后截图即可。
  4. 用 Win+Shift+S 或 PixPin/ShareX 做区域截图。
  5. 需要“背景全透明”时，勾选 导出透明背景，导出 PNG，再用 PixPin/ShareX 贴图置顶。

每行右侧的滑块按钮可以打开「图例样式」：切换面型 / 线型，调整线宽、实线 / 虚线 / 点划线以及虚线间距；面型还可以单独设置边框颜色。线型和边框颜色都能用取色器或 HEX 修改。

没有系统级取色器时，也可以随时截图后按 Ctrl+V（macOS ⌘+V）把截图粘贴到工具里，点击图片取色；或者直接输入 HEX。

左侧分为「图例」和「罗盘」两个设置页，点标签切换。顶部的浮动图例 / 浮动罗盘按钮始终可见，可以随时开/关两扇独立窗口。罗盘页可选指针 / 刻度 / 玫瑰，浅色 / 深色 / 透明卡片，并可调底色不透明度、角度（0° 为正北）和大小；罗盘与图例可同时显示、分别拖动，右键各自打开快捷设置（样式 / 角度 / 背景不透明度 / 关闭）。

图例和罗盘配置会自动保存在本机浏览器，不会上传。浮窗由 启动.bat 启动的后台小程序绘制：整块区域都能拖动，右键打开快捷设置（显示标题 / 列数 / 背景不透明度 / 关闭）；双击色块可直接取色，双击名称或标题可原地改名（回车确认，Esc 取消）。尺寸与导出 PNG 1:1 对应，所以不会模糊；「浮窗背景不透明度」只改背景，文字和符号保持不透明，也不影响导出的 PNG。独占全屏程序、远程桌面或虚拟机可能盖住置顶窗口，请把地图软件设为窗口化或无边框全屏。直接打开 index.html 时小程序没在运行，会退回浏览器画中画窗口。
